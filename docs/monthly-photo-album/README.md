# 月次写真アルバム

みてねとプリントスクエアに渡す写真を、月末に手で集めている作業を軽くするための仕様と調査です。実装はこのディレクトリには含みません。

文書の日付は 2026-09-28 です。OS や API の境界は調査時点のものです。実装に入る前に、使う端末の OS バージョンをもう一度確認してください。

仕様には、利用者から見える挙動と、変えると成果物が変わる判断を書きます。API の版や計測していない速度は調査側に置きます。

実装の手順が必要になったときは `docs/monthly-photo-album/plans/` を足します。この段階では作りません。

## 用語

- **月次アルバム**: ある月の採用写真を入れた、システムの写真アルバム。アプリの中だけに存在する一覧ではありません。
- **候補**: 採点と枚数調整のあと、確定前に人へ見せる写真。
- **確定**: 人が採用を認め、月次アルバムへ書き込むこと。
- **計算ノード**: ライブラリを読み、採点する端末。
- **消費ノード**: みてねやプリントスクエアで、そのアルバムから写真を選ぶ端末。
- **共有向け**: 祖父母など、家族へ見せる相手を想定した評価。
- **印刷向け**: 自宅印刷を想定した評価。
- **出来事**: 近い時刻（と、取れれば位置）で束ねた一群の写真。連写そのものより広い単位です。
